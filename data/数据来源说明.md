# 数据来源说明

## 一、语料来源

研究对象为上市公司年度报告中"第三节 管理层讨论与分析"（MD&A）章节文本。

| 项目 | 说明 |
| --- | --- |
| 数据类型 | 中文年报 MD&A 文本 |
| 覆盖范围 | 300 家上市公司 × 2021、2022、2023 三个会计年度 |
| 文本体量 | 900 篇，平均 1193 字/篇，最短 314 字，最长 3048 字 |
| 存储形式 | `data/corpus/mda_2021.jsonl`、`mda_2022.jsonl`、`mda_2023.jsonl`（每行一条 JSON） |
| 字段 | `firm_id`（证券代码）、`firm_name`（简称）、`industry`（行业）、`year`、`text`（正文） |

**重要说明：本仓库提供的语料为模拟语料，非真实年报文本。**

模拟语料的生成机制见 `code/simulate_corpus.py`，核心设计如下：

1. **潜在困难程度**。每家公司每年设有一个潜在经营困难程度 `d ∈ (0,1)`，
   由三个成分共同决定：公司层面的潜在经营质量 `quality`、隐藏风险因子 `hidden`、
   以及年度宏观冲击。`d` 越高，文本中消极词、不确定词、风险词的投放强度越大，
   积极词的稀缺程度越高。
2. **文本篇幅独立**。篇幅由一个独立于 `d` 的对数正态因子驱动，用于支持
   "区分效度"检验（测度应与文本信息含量这一无关构念不相关）。
3. **语调操纵设定**。约 22% 的公司被设定为存在语调操纵行为，即主动增加
   积极表述、压低消极表述，从而在语调与基本面之间制造系统性背离。
4. **困境标签**。次年是否陷入困境由"文本可反映的风险"与"文本无法反映的
   私有风险"共同决定，使文本语调只是困境的一个有噪声的信号，避免预测能力虚高。
5. **可复现性**。全部随机过程由固定种子 `20261010` 驱动，任何人执行
   `python code/simulate_corpus.py` 都会得到完全一致的结果。

**为什么使用模拟语料？** 本文的研究对象是"测度构建流程"本身。使用模拟语料时，
潜在构念的真值（`_latent_sim.csv`）是已知的，因此可以严格检验"流水线能否正确
还原潜在构念"，这是使用真实数据无法完成的方法验证。真实数据下的应用是后续工作。

## 二、财务与治理变量来源

`data/financials.csv` 记录企业-年份层面的财务与治理变量，与上述语料一一对应（同样为模拟数据）：

| 变量 | 含义 | 生成口径 |
| --- | --- | --- |
| `firm_id` / `firm_name` / `industry` | 标识与行业 | 与语料一致 |
| `age` | 上市年限 | 分段随机，3–26 年 |
| `soe` | 是否国有（1/0） | 伯努利，国有占比约 34% |
| `dual` | 两职合一（1/0） | 伯努利，占比约 26% |
| `top1` | 第一大股东持股比例 | 截断正态，均值约 0.34 |
| `size` | 公司规模（总资产对数） | 均值 13.0，标准差约 0.87 |
| `assets` | 总资产（万元） | `exp(size)` |
| `roa` | 总资产收益率 | 与经营质量正相关的线性结构 |
| `lev` | 资产负债率 | 与经营质量负相关，截断于 [0.05, 0.92] |
| `growth` | 营业收入增速 | 与经营质量正相关 |

## 三、结果变量

`data/distress_label.csv` 给出被解释变量：企业次年是否陷入困境（1/0）。
口径为"按潜在风险排序的 83% 分位切分"，全样本困境比例 17.0%（153/900），
与 A 股市场特别处理事件的实际比例基本吻合。

## 四、真值文件

`data/_latent_sim.csv` 保存仿真的潜在参数真值（`L_text`、`L_distress`、`d`、
`quality`、`hidden`、`manip`），**仅供仿真方法与数据生成机制的说明使用，
不进入任何实证分析样本**。所有实证结果只使用可观测的文本、财务与结果变量。

## 五、分析产出

| 文件 | 内容 |
| --- | --- |
| `data/panel.csv` | 企业-年份面板（900 观测 × 33 列），文本测度与财务变量的合并结果 |
| `results/descriptive_stats.csv` | 主要变量描述性统计 |
| `results/reliability_validity.csv` | 信度与效度检验汇总 |
| `results/correlation_matrix.csv` | Pearson 相关系数矩阵 |
| `results/logit_results.csv` | 5 个 Logit 预警模型的完整系数表 |
| `results/model_fit.csv` | 各模型的伪 R²、AUC、准确率、召回率与最优阈值 |
| `results/robustness.csv` | 8 组稳健性检验结果 |
| `results/summary.md` | 结果摘要（论文引用的全部数字均来自此处） |

## 六、一键复现

```bash
python code/simulate_corpus.py   # 生成语料与财务面板（固定种子，可复现）
python code/pipeline.py          # 执行五步流水线，输出 panel.csv 与 results/
python code/make_docx.py         # 生成 Word 版论文
```

仅需 Python 3.9+ 标准库，无任何第三方依赖。
