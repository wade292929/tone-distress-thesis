# 基于年报文本语调的企业财务困境预警测度研究

> 预演毕业论文 · 五步 NLP 测度构建流水线
> **在线阅读**：https://breeze333-c.github.io/tone-distress-thesis/

用自然语言处理方法从年报文本中构建企业财务困境预警的语调测度，并对测度本身做系统的信度与效度检验。研究把"测度构建"当作研究对象，而非把文本变量当作现成数据。

## 结果速览

| 指标 | 取值 | 判断标准 | 结论 |
| --- | --- | --- | --- |
| 样本规模 | 300 家公司 × 3 年 = 900 观测 | — | — |
| 词典规模 | 108 词（积极34/消极30/不确定20/风险24） | — | — |
| Cronbach's α | **0.704** | > 0.70 | 通过 |
| Spearman-Brown 折半信度 | **0.740** | > 0.70 | 通过 |
| 聚合效度（与备择测度相关） | **0.907** | > 0.60 | 通过 |
| 区分效度（与文本篇幅相关） | **0.218** | \|r\| < 0.30 | 通过 |
| 预测效度（TONE 单独 AUC） | **0.870** | > 0.70 | 通过 |
| 预警模型 AUC（含控制变量） | **0.893** | > 0.75 | 通过 |
| 异常语调增量信息（ABTONE 系数） | **1.381\*\*\*** | z = 8.93 | 显著 |

核心发现：语调变异中只有 34.2% 可由财务基本面还原，在控制基本面后**异常语调仍显著提高次年困境概率**，说明年报语调承载了财务报表未能反映的增量风险信息。

## 五步流水线

| 步骤 | 任务 | 产出 | 关键设计 |
| --- | --- | --- | --- |
| **S1** 语料采集与清洗 | 读入 jsonl、正则清洗 | 规范化文本 | 保留段落结构，剔除异常符号 |
| **S2** 文本预处理与表示 | 句切分、长度统计 | 句子序列与结构变量 | 为句子级极性与离散度预留接口 |
| **S3** 词典构建与情感匹配 | 四类词典、字符串计数 | 四类词频 | 词项互斥、无嵌套包含 |
| **S4** 测度构建 | 5 子指标 → 综合 TONE | 综合语调指标 | 标准化同向化 + 分年度标准化 |
| **S5** 信效度检验与预警建模 | α / 折半 / 三类效度 / Logit | 检验结果与模型 | 四位一体质量检验框架 |

## 一键复现

```bash
python code/simulate_corpus.py   # 生成语料（固定种子 20261010，结果完全可复现）
python code/pipeline.py          # 运行五步流水线 → data/panel.csv + results/
python code/make_docx.py         # 生成 Word 版论文
```

**只依赖 Python 3.9+ 标准库**，零第三方依赖：OLS 用正规方程 + 高斯消元实现，Logistic 回归用牛顿-拉夫森迭代实现，AUC 用 Mann-Whitney U 统计量实现。这样可从根本上消除环境差异导致的复现障碍。

## 三点需要说明

1. **语料为模拟数据**。研究语料由 `code/simulate_corpus.py` 按设定参数生成，潜在风险强度为已知参数，因此可以严格验证"流水线能否正确还原潜在构念"。真实语料下的应用是后续工作。详见 `data/数据来源说明.md`。
2. **词典法口径**。采用直接字符串计数而非先分词再统计，计算过程完全可追溯，避免分词错误带来的词频损失。局限在于无法识别否定与反讽表达，论文中已讨论改进方向。
3. **结果由代码真实计算**。论文中引用的每一个数字都来自 `results/` 目录下的实际运行输出，未做任何人工调整。
